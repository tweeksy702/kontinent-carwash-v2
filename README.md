## 🛠 Как редактировать сайт

### Изменить цены в прайсе:
1. Открой `index.html` в репозитории
2. Найди секцию `<section class="price" id="price">`
3. Измени значения в `<span class="price-num" data-target="1000">1000</span>`

### Изменить номер телефона:
Используй поиск по `+79301811271` и замени на новый номер во всех местах.

### Изменить отзывы:
Найди секцию `<section class="reviews" id="reviews">` и замени текст в `<p class="review-card__text">`.

## 📁 Структура проекта
- `index.html` — главная страница
- `css/styles.css` — все стили и анимации
- `js/main.js` — скрипты (карусель, анимации)
- `netlify.toml` — настройки Netlify
